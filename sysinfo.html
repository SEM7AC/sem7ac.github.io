SEM7AC. SystemInfo

A lightweight .NET library for retrieving CPU, memory, storage, and operating system information through a clean, strongly-typed API. Built to eliminate repetitive WMI code, reduce boilerplate, and provide a modern developer-friendly approach to system information retrieval.

The Problem

Retrieving system information in .NET often means dealing with WMI queries, legacy APIs, ManagementObjectSearcher, verbose boilerplate, and inconsistent results.

While building desktop applications and monitoring tools, I found myself repeatedly writing the same system information code. I wanted a small, dependency-free library that exposed common machine information through a predictable modern API.

The Solution

CPU Information Retrieve processor details including name, cores, logical processors, and clock speed.
Memory Information Access total memory, available memory, utilization, and load metrics.
Storage Information Enumerate system drives with capacity, free space, format, and drive type.
Operating System Information Retrieve OS version, architecture, boot time, and platform details.
No Dependencies Lightweight implementation with no external packages required.
Strongly Typed Models Structured data returned through clean, developer-friendly classes.

Installation

dotnet add package SEM7AC.SystemInfo

Usage Example

var info = new SystemInfoProvider();

var cpu = info.GetCpuInfo();
var memory = info.GetMemoryInfo();
var drives = info.GetStorageInfo();
var os = info.GetOsInfo();
